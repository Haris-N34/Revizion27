# Revizion demo UI
A standalone concept website; no imports from or connections to the Python app, camera, microphone, or hardware.
Open `index.html` directly, or run `python3 -m http.server 8080 --directory demo-ui` from the repo root and visit `http://localhost:8080`.
Choose an object, start, and use Next step to explore simulated guidance. The missing-object option demonstrates the stop flow.
Keyboard and screen-reader controls, optional browser speech, larger text, high contrast, and reduced-motion support are included.
Google Fonts are optional; local sans-serif fallbacks work offline. Browser speech support and offline availability vary.
No build step or package installation is required. Object choices are illustrative and do not declare detector support.
