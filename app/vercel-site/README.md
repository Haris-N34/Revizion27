# REVISION on Vercel

Production: https://revision-live-guidance.vercel.app
Deploy from this directory with `npx vercel --prod` after signing in to Vercel.
This is a static website; no framework, install command, or build command is needed.
The embedded live interface uses the laptop's HTTPS tunnel.
Keep the laptop app, Arduino, and tunnel running for camera and wristband controls.
If the tunnel URL changes, replace both URLs in `index.html` and redeploy.
